A flight controller for a drone, with support for 2 servo motors, based on the Hack Club blueprint guide found here:
https://blueprint.hackclub.com/starter-projects/flightcontroller

I used KiCad, from which I used easyeda2kicad in order to get the footprints and schematic symbols, credited here:

https://github.com/uPesy/easyeda2kicad.py

It uses the STM32F722RET6 as the main brains.
